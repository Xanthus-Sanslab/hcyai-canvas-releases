# HCYAI Canvas Releases

HCYAI Canvas 
是山东世博华创动漫传媒有限公司推出的企业级 AI 创作无限画布。

本仓库仅用于公开发布 Windows 安装包、自动更新元数据、公告与更新日志，不包含 HCYAI Canvas、AI 画布、Agent 或后端的完整源码。

## 下载

- 最新安装包：[GitHub Releases](https://github.com/Xanthus-Sanslab/hcyai-canvas-releases/releases/latest)
- HCYAI 官网：<https://hcyai.cn/>

## 发布内容

每个正式版本的 Release 包含：

- `HCYAI-Canvas-Setup-<version>.exe`
- `HCYAI-Canvas-Setup-<version>.exe.blockmap`
- `latest.yml`

根目录 `HCY_RELEASE_CHANNEL.json` 用于向已安装客户端同步公告与更新日志。只有软件版本号提高时才触发版本更新提示；普通公告变化不会要求重新安装。
